# EpiFive automation

Scheduled GitHub Actions workflows for [EpiFive](https://www.epifive.com). Each workflow checks out EpiFive's private
repository and runs its code there. This repository holds the workflow files and the data files the jobs publish
(for example `radar/live/`, which the website's news pages read).
